# Terminologie opérationnelle

| À éviter | Terme retenu |
|---|---|
| Pré-SSE | Dossier d’intérêt |
| Cible supposée | Sujet d’intérêt |
| Fausse identité | Identité non corroborée |
| Match automatique | Proposition de rapprochement |
| Fusion automatique | Proposition de consolidation |
| Scan personne | Acquisition terrain |
| Fiche définitive | Fiche personne consolidée |
| Tâche terrain | Besoin de collecte |
| Alerte CRON | Signal analytique |

L’état de traitement, le niveau de confiance et la priorité opérationnelle sont indépendants. Les états vont de `BROUILLON` à `ARCHIVÉ`; la confiance de `NON ÉVALUÉ` à `CONFIRMÉ`; l’intérêt de `COURANT` à `CRITIQUE`.
