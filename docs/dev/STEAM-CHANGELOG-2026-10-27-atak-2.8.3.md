[quote]
[b]Important :[/b] quittez Arma 3 complètement après la mise à jour, puis relancez. Le poste doit être à jour pour le temps de jeu et les distances.

[h2]Correction — Identité du compte[/h2]
L’état de liaison ne laisse plus lire l’e-mail, le nom civil ni les détails du terminal par un script de mission.
[list]
[*] Le téléphone reçoit toujours le numéro attribué par Athena ;
[*] les autres opérateurs voient le même numéro sur la carte.
[/list]

[h2]Correction — Marqueurs vers le poste[/h2]
Quand le serveur relaie déjà les repères, le téléphone ne les renvoie plus une seconde fois.
[list]
[*] un repère posé apparaît une seule fois au poste ;
[*] le nom de l’auteur reste correctement affiché.
[/list]

[h2]Correction — Temps de jeu et distances[/h2]
Un poste joueur ne peut plus réécrire le temps de jeu ni les distances des autres opérateurs. Le serveur dédié continue d’envoyer le camp entier.

[h2]Amélioration — Reprise après coupure[/h2]
Après une coupure, le téléphone reprend de lui-même dans la minute et demie. Si le portail demande d’attendre plus longtemps, ce délai est respecté.

[h2]Amélioration — Ouverture du navigateur[/h2]
Seules les pages de liaison, de carte et de 9-LINE du portail s’ouvrent depuis le jeu.

[h2]Amélioration — Raccourci Overwatch[/h2]
Le raccourci « Ouvrir le téléphone ATAK » ouvre le téléphone du pack quand il est chargé. Les opérateurs déjà connus de la liaison apparaissent sur sa carte.
