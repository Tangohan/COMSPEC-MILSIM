# Document 2 : matrice des redondances

Ce document réunit en un seul tableau toutes les redondances relevées par les cinq audits. Les numéros `RD-xx` sont repris dans l'architecture cible (document 3), le plan (document 5) et la matrice de conservation (document 6).

## Comment lire le tableau

| Colonne | Contenu |
|---|---|
| Pages | Identifiants de l'inventaire (document 1) |
| Nature du recouvrement | Ce qui est dupliqué : donnée, écran, route, code |
| Similitude | **Identique** = même donnée, même effet, même code ; **forte** = même donnée et même effet, codes différents ; **moyenne** = même donnée, règles différentes ; **faible** = notions voisines. Qualification reprise des audits (FAIT pour les chemins, jugement pour le degré). |
| Différences métier | Ce qui justifie, ou non, l'existence de plusieurs écrans |
| Mutualisation possible | PROPOSITION |
| Risque | Risque actuel si rien ne change |
| Intérêt | **1** sécurité ou donnée fausse ; **2** friction sur une tâche courante ; **3** configuration dispersée ou incohérence de droits ; **4** cohérence et confort. Les lignes sont triées par intérêt, puis par risque. HYPOTHÈSE : le classement ne s'appuie sur aucune mesure d'usage. |
