# Notes de bugs

Chaque bug identifié doit avoir une note courte dans ce dossier.

Nom conseillé :

- `YYYY-MM-DD-slug-court.md`

Contenu minimal :

- `Contexte`
- `Symptôme`
- `Cause`
- `Correctif`
- `Fichiers touchés`
- `Vérification`
- `Statut`

Exemple de statut :

- `identifié`
- `corrigé`
- `corrigé à vérifier en jeu`
- `bloqué par environnement`
