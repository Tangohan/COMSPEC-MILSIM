# UI page d’erreur 500

## Contexte

Page autonome `views/errors/500.php` affichée lors d’incidents serveur (ex. `/atak/sse/confidentialite` avec base injoignable).

## Symptôme

Composition confuse : texte entièrement en capitales avec tracking trop fort, polices très petites, marque Athena absente, actions en double avec le pied de page, zone noire vide sous la photo.

## Cause

Maquette « tactique » trop dense en uppercase / letter-spacing, sans carte de contenu ni hiérarchie lisible.

## Correctif

- En-tête marque Athena + horodatage
- Carte centrale lisible (casse normale, tailles confortables)
- Hint contextualisé conservé (bandeau ambre)
- Actions : accueil / réessayer / page précédente
- Référence d’incident avec bouton Copier quand disponible
- Pied de page allégé (connexion, mentions légales)

## Fichiers touchés

- `views/errors/500.php`
- `lang/fr/errors.php`
- `lang/en/errors.php`

## Vérification

Ouvrir une URL qui déclenche une 500 (ou inclure la vue avec `$errorHint` / `$errorReference`) et contrôler lisibilité mobile + desktop.

## Statut

corrigé
