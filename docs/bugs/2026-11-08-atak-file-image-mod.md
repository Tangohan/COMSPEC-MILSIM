# ATAK : une erreur de script dans un rappel différé bloquait la file de CBA (téléphone et Arsenal ACE perdus)

- **Contexte** : suite de `2026-11-08-atak-pages-redessinees-file-cba.md`. Seuls les clics de `fn_formRender` et `fn_clickNext` étaient protégés ; 524 rappels `CBA_fnc_execNextFrame` et 162 `CBA_fnc_waitAndExecute` restaient dans la file de CBA.
- **Symptôme** : après une erreur de script dans un rappel différé, le rappel se rejoue à chaque image (alternance oui/non), les rappels suivants (dont ceux d'ACE) ne s'exécutent plus : téléphone et Arsenal ACE perdus jusqu'au redémarrage.
- **Cause** : `CBA_fnc_onFrame` (cba_common 3.19.0, `init_perFrameHandler.sqf`, relu sur le dépôt CBA) appelle les rappels « image suivante » avant d'échanger les tampons, et ne marque un rappel « attendre puis exécuter » comme fait qu'après l'avoir appelé. Une erreur de script interrompt le gestionnaire avant ces étapes.
- **Correctif** : file propre au mod (`fn_frameQueue`, gestionnaire `EachFrame` enregistré au preInit ; `fn_nextFrame` et `fn_waitAndExec`, mêmes arguments, même `_this`, même horloge `CBA_missionTime`, même ordre, même environnement non suspendable). Chaque rappel est retiré de la file avant l'appel : une erreur n'interrompt que l'image en cours de notre gestionnaire, n'est jamais rejouée, et le gestionnaire de CBA n'est plus touché. Rappel interrompu repéré à l'image suivante et noté `[COMSPEC ATAK NATIVE][WARN][FRAME]` (une ligne par 10 s). Insertion dans la file d'attente dans un bloc `isNil` (non suspendable) pour qu'un appel depuis un script `spawn` ne soit pas coupé par le gestionnaire. Files vides : deux comptages par image.
- **Non changé** : CBA reste requis (`waitUntilAndExecute`, PFH, événements, réglages, touches). Overwatch (`mod/UptoDate/Sources/comspec-overwatch-addons`, 73 fichiers) et le SSE gardent leurs rappels CBA : une erreur chez eux peut encore bloquer la file de CBA.
- **Fichiers touchés** : `functions/core/fn_frameQueue.sqf`, `fn_nextFrame.sqf`, `fn_waitAndExec.sqf` (nouveaux), `config.cpp`, `XEH_preInit.sqf`, et les 238 fichiers qui appelaient CBA (substitution pure, vérifiée par comparaison du diff), tous sous `mod/COMSPEC_ATAK_Native/Sources/addons/main/`.
- **Vérification** : en jeu avec `-showScriptErrors` : téléphone, notifications, vibreur, marqueurs PANIQUE / TIC (effacés après 10 min), rendu des pages après un événement de groupe, touches traduites 5 s après l'arrivée ; provoquer une erreur dans un rappel (code de test) : une seule ligne d'erreur, une ligne `[WARN][FRAME]`, puis le téléphone et l'Arsenal ACE répondent ; RPT sans ligne `[WARN][FRAME]` en jeu normal.
- **Statut** : corrigé à vérifier en jeu (ATAK 3.1.0).
