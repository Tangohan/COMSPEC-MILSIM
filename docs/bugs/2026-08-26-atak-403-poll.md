# ATAK — tempête 403 après un 503 (poste + jeu)

## Contexte

Poste web Athena (asset 1.5.48) et Overwatch côté jeu, même fenêtre 20:59–21:02. D’abord un 503 sur les marqueurs, puis des centaines de refus d’accès sur presque toutes les lectures du poste, et les envois jeu (position, caméras, relief, relevé de théâtre).

## Symptôme

Sur le poste : la carte s’ouvre, puis plus aucune donnée (unités, tchat, pings, photos, alertes…). La console se remplit de refus. Les photos de recon n’apparaissent plus.

Dans le journal jeu : refus d’accès en boucle toutes les ~10 s sur la position, les caméras casque, le relief et le relevé — pas seulement le navigateur.

Tuiles Altis hors carte (404) : secondaire, fond de carte, pas un plantage.

## Cause

Ce n’est pas un oubli de jeton de formulaire : le jeu authentifié par clé est refusé en même temps que le poste.

Le filet anti-miroir (et le complément Apache) peut refuser **toute l’adresse réseau** pendant une heure après un piège ou un outil de copie, **y compris** un opérateur déjà connecté et Overwatch. Un burst de lectures après une coupure base (503) donnait l’illusion d’un flood, et le client continuait de marteler.

Le plafond de cadence du portail répondait déjà « trop de requêtes », mais sans délai de reprise, et le client ne s’arrêtait que sur un 503 d’effectifs.

## Correctif

- Anti-miroir : ne pas classer comme copie le jeu (clé / signature Overwatch), les lectures ATAK, ni un compte déjà connecté — y compris les photos de recon.
- Apache : même exception pour la clé, Overwatch et les lectures ATAK.
- Cadence : trop de requêtes = attente + reprise, pas un refus silencieux.
- Poste : après un refus, une saturation ou une coupure, pause 20–30 s de toutes les lectures, un message, puis reprise.
- Jeu : après un refus, pause 30–60 s, un avertissement, position coalescée (un essai), caméras au calme. Une coupure caméra (code 0) reste hors alerte.
- Carte : ne plus demander les tuiles hors théâtre ; le service worker ne transforme plus l’ouverture de la carte en erreur réseau.
