# Bibliothèque de marqueurs

Catalogue des symboles utilisés sur les cartes tactiques du portail (TACMAP, Overwatch) et synchronisés avec le jeu.

## Où la consulter

- Page interactive (aperçus) : `/documentation/marqueurs`
- Depuis le guide : chapitre **Outils cartes & tactique**, lien vers la bibliothèque
- Menu **Aide & recherche** / **Documentation** selon votre navigation

## Organisation

Les marqueurs sont regroupés par usage :

1. **Formes & annotations** — objectifs, alertes, flèches, ralliements
2. **Points d’intérêt** — lieux (médical, bunker, antenne…)
3. **Unités amies / adverses / neutres & civiles / inconnues** — symbologie d’appartenance
4. **Repères tactiques (MarkersPlus)** — points de contrôle, actions, soutien
5. **Contacts & divers**

Chaque fiche affiche un libellé métier en français et, en secondaire, le nom technique utile aux opérateurs.

## Remarque

Les aperçus reprennent le rendu web du portail (symboles OTAN / formes). Les textures converties depuis le jeu, lorsqu’elles sont déployées sous `assets/markers/arma`, peuvent enrichir l’affichage carte sans changer cette légende.
