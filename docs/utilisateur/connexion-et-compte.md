# Connexion et compte

## Connexion

- Saisissez l’adresse **électronique** et le **mot de passe** associés à votre compte.
- Si votre compte est rattaché à **plusieurs** communautés, une étape peut vous demander **laquelle ouvrir** après la connexion.
- En cas d’oubli de mot de passe, utilisez le flux **« Mot de passe oublié »** : un lien de réinitialisation est envoyé à votre adresse (si elle est valide et autorisée).

## Inscription et vérification

- L’**inscription** crée un compte ; selon la configuration, une **validation de l’adresse électronique** peut être obligatoire avant l’accès complet.
- Tant que l’adresse n’est pas validée, certaines actions peuvent être restreintes ou un message vous invite à consulter votre boîte de réception.

## Sécurité du compte

- Le portail peut envoyer des **alertes** (nouvelle connexion, appareil inconnu, etc.) selon les paramètres globaux et vos préférences.
- Vous pouvez être invité à **refuser** un appareil si vous ne reconnaissez pas une connexion (lien de sécurité affiché dans un courriel).

## Espace « Compte » (paramètres personnels)

Rubrique regroupant typiquement :

| Zone | Usage |
|------|--------|
| **Préférences** | Langue, fuseau horaire, thème ou options d’affichage, notifications par courriel. |
| **Photo de compte** | Avatar visible dans la navigation et certaines listes. |
| **Portrait opérateur** | Image « in-universe » pour fiches, ORBAT ou briefings (selon politique de la communauté). |
| **Adresse électronique** | Modification de l’identifiant de connexion (souvent avec confirmation). |
| **Mot de passe** | Changement du secret d’accès. |
| **Profils de candidature** | Préréglages pour accélérer les formulaires d’enrôlement (si activé). |

## Déconnexion

Utilisez la commande **Déconnexion** pour fermer la session sur l’appareil courant, surtout sur un poste partagé.
