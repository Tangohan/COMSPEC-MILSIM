# Communautés

## Définition

Une **communauté** est un espace isolé contenant ses propres membres, documents, forum, formations, événements, etc. C’est l’équivalent d’une **organisation** ou d’une **unité** dans le portail.

## Page publique d’une communauté

Chaque communauté peut disposer d’une **page publique** accessible via son identifiant d’URL (souvent un **court nom** lisible). Vous y trouvez en général :

- Présentation, texte d’accueil, visuels.
- Un moyen de **contacter** les responsables (formulaire public).
- Des boutons pour **rejoindre** le forum ou l’enrôlement **si vous êtes déjà connecté** (sinon, redirection vers la connexion ou l’inscription).

## Rejoindre une communauté

Plusieurs mécanismes peuvent coexister :

- **Invitation** : lien personnel avec code d’invitation ; vous acceptez depuis l’interface dédiée.
- **Code ou lien** : page « Rejoindre » où vous saisissez un code communauté.
- **Création** : un parcours permet de **créer** une nouvelle communauté (souvent avec choix d’offre et paiement en ligne si la facturation est activée).

## Créer une communauté (parcours type)

1. Formulaire d’informations (nom, identifiant d’URL, présentation).
2. Aperçu éventuel avant validation.
3. Paiement ou confirmation selon l’offre (si applicable).
4. Écran de **finalisation** : vous devenez administrateur de cette nouvelle communauté et pouvez inviter des membres.

## Basculer entre communautés

Lorsque votre compte est membre de **plusieurs** communautés :

- Un **sélecteur** ou une action du menu permet de **changer l’organisation active**.
- Le **tableau de bord**, les documents, le forum et les autres modules affichent alors le contenu de la communauté **courante**.
- Les **droits** sont recalculés pour cette communauté (un même utilisateur peut être simple membre dans une organisation et référent dans une autre).

## Registre des communautés

Une liste des communautés **accessibles à votre compte** peut être proposée (connexion requise), pour rejoindre ou ouvrir une communauté sans connaître son identifiant d’URL.

## Offres et limitations

Selon l’**offre** souscrite par la communauté (gratuite, standard, etc.), certaines fonctions (nombre d’événements, modules, etc.) peuvent être **limitées** ou proposer une **mise à niveau** : le portail affiche alors des messages explicites ou des appels à l’action vers l’offre adaptée.
