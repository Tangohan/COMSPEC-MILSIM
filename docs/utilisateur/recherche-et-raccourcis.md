# Recherche et raccourcis

## Recherche portail

Lorsque la recherche est **activée** pour les comptes connectés, vous pouvez :

- Ouvrir la page **Recherche** depuis le menu ou l’icône dédiée.
- Utiliser souvent le raccourci clavier **Ctrl+K** (sur clavier AZERTY/QWERTY selon navigateur) pour ouvrir rapidement la recherche.

La recherche interroge les **types de contenu** autorisés pour votre profil (documents indexés, fiches personnelles accessibles, etc.). Les résultats **excluent** automatiquement ce que vous n’avez pas le droit de voir.

## Affinage des résultats

- Saisissez vos mots-clés dans le champ principal.
- Des filtres additionnels peuvent apparaître selon le module (type de document, unité, etc.).

## Autres raccourcis utiles

- **Navigation au clavier** : utilisez la touche **Tab** pour parcourir les liens ; les menus déroulants peuvent s’ouvrir au clavier selon le navigateur.
- **Déconnexion** : pensez à vous déconnecter sur les postes partagés après usage.
