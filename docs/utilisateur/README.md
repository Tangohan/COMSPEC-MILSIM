# Guide utilisateur Athena

Bienvenue dans la documentation **fonctionnelle** du portail **Athena**. Le **guide intégré** (page « Guide du portail », connecté) est la référence principale pour les membres et l’encadrement : manuel métier exhaustif, chapitre par chapitre. Les fiches Markdown ci-dessous complètent ou détaillent certains modules pour l’équipe projet.

## À qui s’adresse ce guide ?

- **Membres** d’une communauté (lecture, participation, formations, documents autorisés).
- **Référents** ou **cadres** (animation, suivi des recrutements, paramétrage léger selon les droits).
- **Administrateurs d’organisation** (back-office : utilisateurs, rôles métier, événements, modération, etc.).

Les droits visibles à l’écran peuvent varier : un même écran peut être **masqué**, **en lecture seule** ou **complet** selon votre profil et la communauté dans laquelle vous vous trouvez.

## Principes du portail

| Concept | Explication |
|--------|-------------|
| **Compte** | Identité de connexion (adresse électronique, mot de passe). Un compte peut appartenir à **plusieurs** communautés. |
| **Communauté** | Espace dédié à une unité / un groupe : personnel, documents, forum, formations, etc. Vous **basculez** d’une communauté à l’autre sans vous reconnecter. |
| **Session** | Tant que vous êtes connecté, le portail « se souvient » de la communauté active et de vos droits. |
| **Permissions** | Droits calculés par le système (lecture documentaire, modération forum, accès back-office…). Vous voyez seulement ce qui vous est autorisé. |

## Convention de lecture

- Les **chemins** indiqués (ex. « Documents », « Formations ») correspondent aux **entrées du menu** ou aux **rubriques** du portail, pas à des adresses techniques.
- Lorsqu’une fonction dépend d’un **abonnement**, d’un **module activé** ou d’un **droit spécifique**, c’est indiqué dans le chapitre concerné.
