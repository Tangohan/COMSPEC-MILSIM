# Formations

## Principe

Le module **Formations** (académie) permet de diffuser des **parcours** structurés : cours, leçons, ressources, quiz et, le cas échéant, **attestations** ou certificats de complétion.

La disponibilité du module peut dépendre de l’**offre** souscrite par la communauté et de l’activation des fonctionnalités pédagogiques.

## Catalogue

- Liste des **parcours publiés** accessibles dans la communauté active.
- Filtres possibles par **thème** ou **recherche** selon l’interface.
- Chaque parcours mène à une **fiche détaillée** : objectifs, durée indicative, modules ou leçons.

## Mes formations

Vue « **Mes formations** » : parcours **assignés** ou **démarrés** par vous, avec état d’avancement (en cours, terminé, expiré si une date limite existe).

## Suivre un parcours

1. Ouvrir un parcours depuis le catalogue ou « Mes formations ».
2. Parcourir les **leçons** dans l’ordre indiqué (ou librement si la politique le permet).
3. Consulter les **ressources** jointes (PDF, liens, vidéos selon contenu).
4. Réussir les **quiz** si le parcours en comporte : une tentative peut être enregistrée, avec score minimal requis.

## Quiz et attestations

- Les **quiz** valident les acquis ; en cas d’échec, une nouvelle tentative peut être proposée selon les règles du parcours.
- Une **attestation** ou certificat peut être généré lorsque le parcours est **complété** et que les conditions sont remplies.

## Administration pédagogique (rôles autorisés)

Les profils disposant des droits de **gestion** ou **publication** des formations accèdent à des écrans d’administration (catalogue éditorial, inscriptions, rapports, studio de contenu selon configuration). Ces écrans permettent de créer ou modifier des parcours **pour la communauté courante**.
