# Événements, pointage et messages internes

## Événements communautaires

La rubrique **Événements** liste les **séances**, **opérations** ou **réunions** planifiées par la communauté.

- Chaque événement affiche **horaires**, **lieu** ou serveur, et une **description**.
- Vous pouvez souvent **confirmer votre présence** (RSVP) : oui, non, peut-être — selon les options proposées.
- Des **rappels** par courriel peuvent être envoyés automatiquement avant l’événement.
- Une **annulation** par l’organisateur peut déclencher une notification aux participants.

## Pointage

Le **pointage** complète ou remplace la simple liste d’événements pour la **présence opérationnelle** :

- Vue des créneaux ou missions concernant votre communauté.
- Actions possibles : **inscription** à un créneau, **pointage** sur place (check-in) si un mécanisme est prévu.
- Les règles exactes (qui peut pointer, fenêtre horaire) sont définies par votre organisation.

## Messages internes

Les **messages internes** sont une **messagerie** limitée à la communauté active — distincte du forum (qui est public aux membres autorisés) et du courrier officiel (workflow formel).

Fonctionnement habituel :

- **Boîte de réception** avec fils ou conversations.
- **Nouveau message** : choix du ou des destinataires autorisés, objet, contenu.
- **Réponses** dans le fil pour garder le contexte.

Les notifications par courriel peuvent alerter de nouveaux messages selon vos **préférences de compte**.
