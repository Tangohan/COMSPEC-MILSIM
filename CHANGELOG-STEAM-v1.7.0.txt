## ⚙️ Installation

### Serveur
1. Exécuter `php setup-realism-migration.php --tenant-id=1`
2. Vérifier `/admin/atak/realism/verify` (tous tests ✅)

### Mod
1. Recompiler l'extension C# avec les nouvelles méthodes
2. Générer `app_relay_ca.paa` avec Arma 3 Tools
3. Rebuild les PBOs avec Addon Builder
4. Copier `@comspec_overwatch` sur le serveur
