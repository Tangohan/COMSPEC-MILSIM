## Version BBCode (FR) — coller dans Steam

```
[h1]COMSPEC SSE[/h1]

[b]Sensitive Site Exploitation[/b] pour Arma 3 : générer, collecter et transmettre le renseignement terrain (personnes, sites, numérique, biométrie simulée) — avec Zeus, l’éditeur et ACE.

Conçu pour les unités milsim et les chefs de mission qui préparent un théâtre exploitable, sans remplacer la décision humaine.

[h1]Ce que fait le pack[/h1]
[list]
[*] [b]Génération déterministe[/b] — identités, sites, téléphones, documents, selon un scénario ou un modèle.
[*] [b]Zeus[/b] — modules COMSPEC SSE : site, brief, modèles, contrôle, file à exploiter.
[*] [b]Éditeur[/b] — attributs et modules pour poser le renseignement dès la mission.
[*] [b]ACE[/b] — inspecter, photographier, fouiller, exploiter un appareil, ouvrir le terminal.
[*] [b]SEEK II[/b] — biométrie simulée (visage, empreintes) autour d’un même dossier.
[*] [b]Liaison Athena[/b] — si COMSPEC Overwatch est chargé, le renseignement remonte au bureau.
[/list]

[h1]Prérequis[/h1]
[list]
[*] [b]Arma 3[/b]
[*] [b]CBA A3[/b] (obligatoire) — [url=https://steamcommunity.com/sharedfiles/filedetails/?id=450814997]Workshop CBA[/url]
[*] [b]ACE3[/b] (obligatoire) — [url=https://steamcommunity.com/sharedfiles/filedetails/?id=463939057]Workshop ACE3[/url]
[*] [b]COMSPEC Overwatch[/b] (optionnel) — pour envoyer vers Athena
[/list]

[h1]Installation[/h1]
[olist]
[*] Abonnez-vous à ce pack (et à CBA + ACE3).
[*] Dans le lanceur Arma 3, activez [b]CBA A3[/b], [b]ACE3[/b], puis [b]COMSPEC SSE[/b].
[*] Overwatch ensuite, si vous reliez Athena.
[*] Relancez Arma complètement après une mise à jour — pas seulement la mission.
[/olist]

[h1]Liens[/h1]
[list]
[*] Athena : [url=https://athena.ttrd.fr]https://athena.ttrd.fr[/url]
[/list]

[h1]Crédits[/h1]
COMSPEC. Dépend de CBA A3 et ACE3 (communauté Arma). Voir CREDITS.md dans le pack.
```
