# Guides des outils COMSPEC SSE

Un guide complet par outil : à quoi il sert, où le trouver (Zeus, Eden, ACE, téléphone ATAK, menu Échap), pas à pas sur un exemple de jeu, chaque champ et réglage, pièges fréquents, lien avec Athena. Le même contenu, en plus court, est dans le jeu : **MANUEL SSE** (Échap › Manuel de terrain › COMSPEC SSE ; au Zeus : module « Ouvrir le manuel » ; dans Eden : menu COMSPEC SSE ; dans chaque fenêtre SSE : le bouton « ? »).
