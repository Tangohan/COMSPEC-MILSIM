# Demo SSE

Le fichier `init.sqf` peut être copié dans une mission VR Eden.

Le `mission.sqm` complet doit être créé depuis l'éditeur (fichier minimal non fourni pour éviter un SQM invalide).

Procédure :
1. Créer une mission VR vide dans Eden
2. Remplacer / fusionner `init.sqf` avec celui de ce dossier
3. Charger `@COMSPEC_SSE` + CBA + ACE
4. Prévisualiser → un civil + téléphone SSE apparaissent près du joueur
