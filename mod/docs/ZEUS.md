# Zeus — COMSPEC SSE

Catégorie : **COMSPEC — SSE**

## Modules V0.1

| Module | Effet |
|--------|-------|
| Générer profil SSE | Génère données + ouvre dialogue (profil, richesse, bruit %) |
| Créer site SSE complet | `generateSite` sur la position / zone |
| Appliquer modèle SSE | Applique un modèle builtin/user (dialogue) |
| Enregistrer comme modèle SSE | Capture la cible en modèle réutilisable |
| Lister modèles SSE | Inventaire des modèles disponibles |
| Initialiser cible SSE | `makeSearchable` lazy |
| Voir données SSE | Affiche UID / profil / état / liens |
| Effacer données SSE | Reset variables |
| SSE Debug Inspector | Overlay 3D + `drawLine3D` des relations |

## Utilisation

1. Ouvrir Zeus
2. Modules → COMSPEC — SSE
3. Glisser « Générer profil SSE » sur une unité
4. Régler Profil / Richesse dans les arguments module
5. Valider → dialogue GÉNÉRER

## Debug

Activer le module Debug Inspector puis pointer une entité : UID + état + lignes de relations.
