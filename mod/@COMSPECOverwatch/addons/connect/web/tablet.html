Vue Commande

Console embarquée inspirée des systèmes de commandement de bataille (suivi des forces bleues). La carte topo centrale affiche vos unités en liaison, comme un poste véhicule de type Appliqué.

À quoi ça sert

Situer ses forces, lire les messages de combat, consulter l’état de liaison et lancer les applications tactiques — dans l’esprit Force XXI, puis des versions modernisées à débit satellitaire accru.

Touches de fonction

F1 Carte · F2 Filtres / noms · F3 Messages de combat · F4 Messagerie · F5 État · F6 Admin · F7 Applications · F8 Aide

Carte

La carte centrale affiche le terrain Arma (routes, relief, satmap) avec vos unités en liaison. Utilisez Zoom, Recentrer, ou Menus pour revenir aux écrans Messages / Combat / Apps.

Repères console
Bandeau vert — niveau de classification affiché
Voyants bas — liaison · sync · alertes
Rail droit — menus F1 à F8 (grille 2×4)
Contexte (ambiance)
Hérité des concepts Force XXI / suivi des forces (BFT), puis des versions jointes modernisées. Ici : présentation milsim Overwatch, pas un clone officiel.
