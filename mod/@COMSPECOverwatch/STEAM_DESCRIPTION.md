## Version BBCode (FR) — coller dans Steam

```
[h1]COMSPEC Overwatch[/h1]

Reliez Arma 3 à [b]Athena[/b] : votre carte tactique, votre messagerie et votre téléphone dans la même boucle que le jeu.

Conçu pour les unités milsim et les missions où l’image tactique doit être partagée entre le terrain (en jeu) et le poste de commandement (sur Athena).

[h1]Fonctionnalités[/h1]
[list]
[*] [b]Liaison Athena[/b] — connectez votre compte avec un code depuis le site (menu en jeu).
[*] [b]Position synchronisée[/b] — votre position apparaît sur la carte tactique Athena.
[*] [b]Tablette Overwatch[/b] — écran tactique en jeu pour consulter et agir.
[*] [b]Téléphone[/b] — couplez votre mobile (QR) pour suivre la situation hors du clavier.
[*] [b]Messagerie[/b] — échanges rapides avec le dispositif (Ctrl+K par défaut).
[*] [b]Indicatif[/b] — définissez / synchronisez votre callsign.
[*] [b]Ordres reçus[/b] — boîte de réception des ordres transmis depuis Athena.
[*] [b]Appui aérien[/b] — demande type « 9 lignes ».
[*] [b]Briefing[/b] — tableau de briefing et diapositives préparées côté Athena.
[*] [b]Opérations aériennes[/b] — manifeste de vol / suivi ops air.
[*] [b]Terrain[/b] — signaler un point d’intérêt, transmettre un bilan de santé.
[/list]

[h1]Prérequis[/h1]
[list]
[*] [b]Arma 3[/b]
[*] [b]CBA A3[/b] (obligatoire) — [url=https://steamcommunity.com/sharedfiles/filedetails/?id=450814997]Workshop CBA[/url]
[*] Un [b]compte Athena[/b] pour la liaison complète : [url=https://athena.ttrd.fr/public]athena.ttrd.fr/public[/url]
[/list]

[h1]Installation[/h1]
[olist]
[*] Abonnez-vous à ce mod (et à CBA A3).
[*] Dans le lanceur Arma 3, activez [b]CBA A3[/b] puis [b]COMSPEC Overwatch[/b].
[*] Lancez une mission, ouvrez le menu Overwatch ([b]touche K[/b] par défaut).
[*] Sur Athena : générez un [b]code de liaison[/b], puis en jeu : [b]Compte Athena[/b] → coller le code.
[/olist]

Astuce : en solo / éditeur, si la liaison ne démarre pas, vérifiez les options BattlEye du lanceur (certains outils du mod peuvent être bloqués tant qu’ils ne sont pas autorisés).

[h1]Raccourcis (par défaut)[/h1]
[list]
[*] Menu Overwatch : [b]K[/b]
[*] Messagerie : [b]Ctrl+K[/b]
[/list]
(Réassignables via Options → Configurer les addons → COMSPEC Overwatch.)
```

## Version Markdown (miroir dépôt)

### COMSPEC Overwatch

Reliez Arma 3 à **Athena** : carte tactique, messagerie et téléphone dans la même boucle que le jeu.

Conçu pour les unités milsim et les missions où l’image tactique est partagée entre le terrain (en jeu) et le poste de commandement (sur Athena).

#### Fonctionnalités

- **Liaison Athena** — code depuis le site, menu en jeu
- **Position synchronisée** sur la carte Athena
- **Tablette Overwatch** — écran tactique
- **Téléphone** — couplage mobile (QR)
- **Messagerie** (Ctrl+K)
- **Indicatif**, **ordres reçus**, **appui aérien (9 lignes)**
- **Briefing**, **opérations aériennes**
- **Point d’intérêt**, **bilan de santé**

#### Prérequis

- Arma 3
- [CBA A3](https://steamcommunity.com/sharedfiles/filedetails/?id=450814997) (obligatoire)
- Compte [Athena](https://athena.ttrd.fr/public) pour la liaison complète

#### Installation

1. Abonnez-vous au mod (+ CBA).
2. Activez **CBA A3** puis **COMSPEC Overwatch** dans le lanceur.
3. En jeu : touche **K** → menu Overwatch.
4. Sur Athena : générer un code de liaison → en jeu : **Compte Athena**.
