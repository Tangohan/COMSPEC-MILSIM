# Calage IceMan — largeur minimale

Copies des fichiers IceMan / BCE corrigés (ressort du téléphone).
Le jeu se fermait tout seul : le cadre passait sous zéro, même sans
ouvrir Athena.

Le PBO corrigé se nomme `BCE_UI_Anim.pbo` et se copie dans le pack FN
(`@# S.O.A.R - FN\addons`).

`BCE_UI_Anim.pbo.orig` = version IceMan d’origine, pour revenir en arrière.
