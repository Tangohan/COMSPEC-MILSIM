# Iceman ATAK HAHO/HALO

Companion addon for BCE/cTab ATAK jump planning.

Initial procedure model:
- HAHO assumes jumpers pull after 3.5 seconds.
- HALO assumes jumpers pull at 300m AGL.
- Canopy procedure speed is fixed at 30 kph.
- Planning includes a 20 percent correction/stack safety factor and a 75m landing reserve.

Pack this folder as `ATAK_HAHO_HALO` under the prefix `\ATAK_HAHO_HALO`.
