# ATAK TOC Screens

Adds an ACE interaction to likely screens, computers, map boards, and consoles.

The action opens a setup UI that can stream helmet cameras, UAV cameras, and air vehicle camera fallbacks onto a screen object's surface selection. A panel fallback remains for odd objects that cannot take a surface texture cleanly.

Profiles save offset, pitch, roll, surface selection, vision mode, and PiP view distance so common screen setups can be reused quickly.
