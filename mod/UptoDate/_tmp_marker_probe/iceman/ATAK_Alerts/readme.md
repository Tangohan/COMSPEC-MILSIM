# Iceman ATAK Alerts

Owns TIC and Eagle Down alerts for the Iceman ATAK tools.

- Sends TIC, TIC clear, and Eagle Down reports to all players with ATAK/cTab leader devices.
- Stores received alerts locally in the Alerts page and cTab message store.
- Hooks the existing cTab TIC alert function so the normal TIC workflow still works.

Pack this folder as `ATAK_Alerts` under the prefix `\ATAK_Alerts`.
