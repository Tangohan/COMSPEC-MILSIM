# Iceman ATAK BDA

Owns BDA reports for the Iceman ATAK tools.

- Patches the existing BCE/cTab `BDA Report` ATAK tile.
- Sends BDA reports to all players with ATAK/cTab leader devices.
- Stores received BDA reports locally in the BDA page and cTab message store.

Pack this folder as `ATAK_BDA` under the prefix `\ATAK_BDA`.
