# Iceman ATAK Elevation

Adds an Elevation App to the ATAK desktop.

Modes:
- View Shed: pick a point, set observer height in feet, set radius, and generate visible/deadspace terrain overlay.
- Heatmap: pick a square center, set area size and sample spacing, and generate a topographical height overlay.

Pack this folder as `ATAK_Elevation` under the prefix `\ATAK_Elevation`.
